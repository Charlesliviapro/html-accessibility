Introduction to Web Accessibility

This page demonstrates key accessibility features including proper semantic HTML, alt text for images, skip-to-content links, ARIA roles and labels, keyboard navigation, and visible focus states. All these features help make web content accessible to everyone, including users with disabilities.

Images with Alt Text

All images should have descriptive alt text. Decorative images should use empty alt text (alt="").

Informative Image

Alt text: "Bar chart showing quarterly sales growth from Q1 to Q4, with values increasing from $50k to $120k"

Decorative Image

Alt text: Empty (alt="") or role="presentation" for decorative images

Keyboard Navigation Examples

All interactive elements should be keyboard accessible. Try using Tab, Shift+Tab, Enter, Space, and Arrow keys to navigate.

Button Group (Tab Navigation)

Use Tab to move between buttons, Enter or Space to activate.

Tab Interface (Arrow Key Navigation)

Use Tab to focus the tab list, then Left/Right arrows to navigate tabs, Enter to activate.

ARIA Roles and Live Regions

ARIA (Accessible Rich Internet Applications) provides semantic meaning to content and helps assistive technologies understand dynamic content.

ARIA Live Region Example

Click the button to see a live region announcement (screen readers will announce the change).

Common ARIA Roles Used in This Page

  • role="banner" - The page header
  • role="navigation" - Navigation menu
  • role="main" - Primary content area
  • role="tablist" - Tab navigation container
  • role="tab" - Individual tabs
  • role="tabpanel" - Tab content panels
  • role="status" - Status message region
  • role="img" - Image with description
  • role="presentation" - Decorative content
